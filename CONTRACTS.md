### `protocol/messages.dart`

```dart
enum ObcMessageType { buttonState(0x01), deviceStatus(0x02), haptic(0x03), appInfo(0x04) }

class ButtonStateMessage {
  final Map<int, int> buttons; // id -> 0 released, 1 pressed, 2..255 analog
  ButtonStateMessage(this.buttons);
  List<int> encode();
  static ButtonStateMessage decode(List<int> bytes);
}

class DeviceStatusMessage {
  final int battery; // 0..100 or 0xFF
  final bool connected;
  List<int> encode();
  static DeviceStatusMessage decode(List<int> bytes);
}

class HapticMessage {
  final int pattern, duration10ms, intensity;
  List<int> encode();
  static HapticMessage decode(List<int> bytes);
}

class AppInfoMessage {
  final String appId, appVersion;
  final List<int> supportedButtons;
  List<int> encode();
  static AppInfoMessage decode(List<int> bytes);
}

/// Stream decoding for TCP or notifications: returns message plus consumed bytes.
sealed class ObcMessage {}
class ButtonState extends ObcMessage { final Map<int,int> buttons; }
class DeviceStatus extends ObcMessage { final int battery; final bool connected; }
class HapticCommand extends ObcMessage { final int pattern, duration10ms, intensity; }
class AppInfo extends ObcMessage { final String appId, appVersion; final List<int> supportedButtons; }

class ObcCodec {
  /// Attempts to decode one message at the head of the buffer.
  /// Returns null when the buffer is incomplete.
  static ({ObcMessage message, int consumed})? tryDecode(List<int> buffer);
}
```

Validation rules: maximum length 20 bytes for `0x01` (discard and resynchronise beyond that); unknown bytes ignored; `0x04` rejected when lengths are inconsistent.

### `shifting/`

```dart
enum RidingMode { sim, erg }

class GearRatio {
  final double ratio;      // relative development, > 0
  const GearRatio(this.ratio);
}

class GearProfile {
  final String id, label;
  final List<GearRatio> gears;         // 1..30
  final GearRatio? bigChainringFactor; // optional virtual chainring
}

class GearEngine {
  GearEngine({required GearProfile profile, int initialGear = 0, RidingMode mode = RidingMode.sim});
  int get gearIndex;                  // 0-based
  int get gearCount;
  RidingMode get mode;
  GearRatio get currentRatio;
  bool get atLowest, atHighest;

  /// Returns true when the gear changed.
  bool shiftUp();
  bool shiftDown();
  bool setGear(int index);
  void toggleChainring();             // virtual chainring
  void setMode(RidingMode mode);

  /// Resistance to apply to the trainer, in simulated watts.
  double targetResistance({required double gradePercent, required double riderWeightKg, required double speedKmh});
  /// In ERG: current watt target (buttons adjust by +-5 W).
  int get ergTargetWatts;
  int bumpErg(int deltaWatts);
}
```

Default profiles: `road-12` (12 even gears), `hill-24`, `flat-8`. Ratios normalised between 0.45 and 3.2.

## Package `transports` (Dart, depends on `core`)

```dart
abstract class Transport {
  String get id;              // "mdns_tcp", "ble_peripheral", "local", "proxy"
  Future<void> start();
  Future<void> stop();
  Stream<TransportEvent> get events; // connected, disconnected, error, action received
  Future<void> emit(Action action);
}
```

- `MdnsTcpTransport`: advertises `_openbikecontrol._tcp`, required TXT records, TCP server, encodes `0x01` and `0x02`, decodes `0x03` and `0x04`.
- `BlePeripheralTransport`: interface plus a per-platform backend wired later (documented stub, no silent dead code: throw an explicit `UnimplementedError`).
- `LocalInjectionTransport`: interface to the key/touch injector.
- `TrainerProxy`: FTMS connection, grade read, resistance write.

## Package `app` (Flutter)

- Screens: Controllers, Trainer, Target, Diagnostics.
- No business logic in widgets: everything goes through `core` and `transports`.
- A test-bench screen that injects fake button presses.

## Conventions

- All public code is documented in English; identifiers are in English.
- No third-party product or brand names in code, comments or fixtures.
- Tests: `dart test` for `core` and `transports`, `flutter test` for `app`.
